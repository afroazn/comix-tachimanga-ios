# Comix for Tachimanga iOS

Independent research project to investigate the Comix manga source error (`Could not find manga API`) on Tachimanga for iPhone.

**Status: investigation only. Not an installable or verified working iOS extension.**

Upstream source: https://github.com/keiyoushi/extensions-source/tree/main/src/en/comix

Upstream issue: https://github.com/keiyoushi/extensions-source/issues/19830

The upstream Keiyoushi code is Apache-2.0 licensed; preserve attribution and licence when copying source.

## Plan
1. Identify Tachimanga's compatibility requirements and the upstream extension dependencies.
2. Import a documented, licensed Comix code snapshot into this repository.
3. Diagnose manga API discovery and develop a narrow fix.
4. Test the patch in Tachimanga on iPhone before publishing any extension index or releases.
